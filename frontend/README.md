# Intelligent Network Routing - Frontend

This is the React + Vite frontend for the Intelligent Network Routing Simulator.

## How to Run

To start the frontend development server:

```bash
npm install
npm run dev
```

The frontend will be available at `http://localhost:5173`. 

**Note:** The frontend requires the FastAPI backend to be running to function properly. Please see the [root README.md](../README.md) for full project startup instructions.
